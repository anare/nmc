# 04 — internal/ui

Drawing primitives and the colour theme. No state, no event handling.

## Geometry

```go
type Rect struct{ X, Y, W, H int }
func (r Rect) Right() int  { return r.X + r.W }
func (r Rect) Bottom() int { return r.Y + r.H }
```

## Text

| Function | Does |
| --- | --- |
| `Text(s, x, y, maxw, str, style) int` | draw, clipped; returns cells used |
| `TextPadded(...)` | draw, then fill the rest of the span |
| `TextRight(...)`, `TextCenter(...)` | aligned within a span |
| `Truncate(str, maxw)` | cut to display width, `~` marks the cut |
| `TruncateLeft(str, maxw)` | keep the tail — for paths |
| `Fill(s, rect, style)` | blank a region |

**Every one of these measures in display columns, not bytes or runes.**
`go-runewidth` gives the width; a CJK character is two columns and an
emoji can be two. `Text` drops a wide rune that would straddle the right
edge rather than letting it overflow — a half-drawn wide character corrupts
the cell after it.

## Boxes

```go
type BoxChars struct{ TL, TR, BL, BR, H, V, LT, RT, TT, BT rune }
var Single = BoxChars{'┌','┐','└','┘','─','│','├','┤','┬','┴'}
var Double = BoxChars{'╔','╗','╚','╝','═','║','╠','╣','╦','╩'}
```

`DrawBox`, `HLine`, `VLine`. Panels use `Single`, dialogs use `Double`.
`HLine`/`VLine` draw tee characters where they meet a frame.

## Theme

One struct of `tcell.Style` values, built by `DefaultTheme()`. The default
skin is mc's: navy background, cyan frames, cyan selection bar, grey
dialogs, white-on-red errors.

### File type colours

| Colour | Class |
| --- | --- |
| bold white | directory |
| bold green | executable |
| cyan | symlink |
| bold red | broken symlink |
| olive | device, socket, fifo |
| magenta | archive |
| purple (MediumPurple) | image |
| orange (DarkOrange) | audio and video |
| sky blue (LightSkyBlue) | source |
| tan | document |
| khaki | data and configuration |
| grey | build output, editor leftovers |
| silver | anything else |

`FileTypeStyle(e)` is **one case per class with no fall-through**: a file
has exactly one kind, so a missing case draws it in the default colour
rather than a wrong one.

`EntryStyle(e, marked, cursor)` layers state over type: cursor and mark win,
as in mc. Under the selection bar every file is black-on-cyan; marked files
are yellow throughout.

Two tests guard the palette and both were confirmed to fail when
deliberately broken:
- no two classes share a (foreground, bold) pair
- no class is drawn in the panel's background colour

## The hint bar

`DrawHintBar(s, y, w, theme, labels [10]string)` — ten slots sharing the
width evenly, leftover cells spread over the first few so the bar always
reaches the right edge. The number is in `HintKey` style, the label in
`HintLabel`.

**The labels for the panel, viewer, editor and find screens are computed
from the live key bindings** (`app.hintLabels`), not from a table here.
A static table would advertise `5Copy` after copy had been moved to F6.
Only the screens whose keys are fixed — settings, key tester, git history —
have constant label arrays in this package.
